# Course Management System

A Java-based Course Management System designed to manage students, courses, and course enrollment operations.

## About the Project

Course Management System is a Java application developed to practice object-oriented programming and layered application design.

The application provides a structured approach to managing students and courses through separate Model, Service, and Repository components.

## Project Features

- Student management
- Adding students to the system
- Course management
- Adding courses to the course repository
- Student course enrollment operations
- Service-based application logic

## Project Architecture

The application follows a package-based structure:

```text
CourseMenegment/
│
├── src/
│   ├── Main.java
│   │
│   └── CourseMenegment/
│       ├── Db/
│       │   └── Repository.java
│       │
│       ├── Model/
│       │   └── Course.java
│       │
│       └── Service/
│           └── AdminService.java
│
└── README.md
```

## Getting Started

### Requirements

- Java JDK
- IntelliJ IDEA or another Java-compatible IDE

### Installation

Clone the repository:

```bash
git clone https://github.com/SENAN111/CourseMenegment.git
```

Open the project in IntelliJ IDEA.

Configure your Java JDK and run `Main.java`.
